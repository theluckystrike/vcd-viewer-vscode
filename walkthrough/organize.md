# Radix, buses and names

| Do this | To |
|---|---|
| Radix menu | Show the selected signals in hex, binary, unsigned, signed or ASCII |
| Ctrl/Cmd + click, Shift + click | Select several signals |
| `G` or Bus | Group the selected signals into one bus. The top one is the most significant bit. Press again to split it. |
| `F2` or double-click a name | Rename a signal. The real name stays in the tooltip. |
| Drag a row, or Alt + Up/Down | Move signals |
| `Delete` | Remove the selected signals from the view |
| Double-click a value | Copy it |

x values are red and z values are yellow, in the waves and in the Value column.
